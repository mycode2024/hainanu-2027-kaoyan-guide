# 海南大学 2027 考研导航多页面改造设计

## 背景

现有版本把官方动态、专业选择、全年时间轴、报名、材料、初复试、风险和官方信源全部放在一个页面中。内容本身有价值，但用户需要长距离滚动，顶部目录同时承担站点导航和页内导航，移动端尤其显得冗长。

这次改造把网站变成真正的多页面信息架构，而不是在原页面上折叠内容。页面仍由同一个零依赖 Node.js 服务提供，仍保留本地自动抓取、缓存保护、严格静态白名单和 21 项行动进度。

## 目标

- 将内容拆成五个职责单一、可直接刷新和收藏的页面。
- 首页只回答“现在处于什么阶段、下一步做什么、整体完成多少、去哪里看详情”。
- 保留原有全部关键内容、21 个 `data-check-id`、14 个时间节点、实时更新能力和免责声明。
- 21 项进度在页面之间合并保存，任何一个子页面都不能覆盖其他页面的状态。
- 首页在没有完整时间轴 DOM 的情况下仍能动态显示当前阶段与下一节点。
- 每个页面具有正确的标题、唯一 `h1`、当前页导航状态、移动端导航和独立打印能力。
- Node.js 服务继续只暴露明确列入白名单的文件，未知路径和项目源码仍不可访问。

## 非目标

- 不引入前端框架、构建工具、数据库或第三方运行时依赖。
- 不更改官方抓取器、更新服务、刷新频率或缓存格式。
- 不把预计日期提升为已确认日期，也不改写现有招生事实。
- 不部署到公网、不推送远程仓库。

## 页面与路由

| 页面 | 文件 | 规范导航地址 | 服务兼容别名 | 职责 |
| --- | --- | --- | --- | --- |
| 首页 | `index.html` | `/` | `/index.html` | 当前阶段、下一节点、全局进度、真值提示、五页入口、最新官方通知摘要 |
| 专业与备考 | `programs.html` | `/programs.html` | `/programs` | 三个专业基线、408/复试、备考节奏、风险提醒 |
| 全年时间轴 | `timeline.html` | `/timeline.html` | `/timeline` | 14 个里程碑、分类筛选、10 项阶段清单 |
| 报名材料 | `application.html` | `/application.html` | `/application` | 报考单位与报考点、八步报名、8 项材料清单 |
| 官方动态 | `updates.html` | `/updates.html` | `/updates` | 完整实时控制台、来源健康、官方原文与联系方式 |

导航使用 `.html` 地址，使 `scripts/serve.cjs` 和直接静态文件模式也能自然工作；生产服务同时提供无扩展别名。生产服务的 `PUBLIC_FILES` 继续使用显式 `Map`，不得改为按请求路径拼接文件。

## 内容分配

### 首页

- 保留品牌、2027 计算机 408 定位和核心免责声明。
- 保留动态阶段仪表盘，但从共享里程碑数据读取标题与行动，不依赖时间轴页面的 DOM。
- 显示全站 `已完成 / 21 项`，并提供明确的“重置全部 21 项”操作。
- 用入口卡替代完整专业卡、完整时间轴、报名步骤和材料清单。
- 保留一个紧凑官方动态摘要：同步状态、手动同步按钮、最新 3 条公告和进入完整动态页的链接；不在首页复制来源健康指标和全部公告。

### 专业与备考

- 原 `programs`、`exam`、`risks` 内容完整迁移。
- 三个专业选择复选框保持原 ID：`program-academic`、`program-computer`、`program-software`。
- 2026 目录、2027 科目调整、408 大纲与复试权重均保留“基线/参考”语义。

### 全年时间轴

- 原 `timeline` 的 14 个里程碑和筛选器完整迁移。
- 保留 10 个阶段复选框：`stage-baseline`、`stage-directory`、`stage-preapply`、`stage-apply`、`stage-confirm`、`stage-ticket`、`stage-exam-logistics`、`stage-retest-material`、`stage-retest-plan`、`stage-archive`。
- 当前阶段仍使用 `aria-current="step"`，预计/参考标签不得删除。

### 报名材料

- 原 `apply-guide` 和 `materials` 完整迁移。
- 保留 8 个材料 ID：`material-id`、`material-student`、`material-photo`、`material-point`、`material-file`、`material-contact`、`material-special`、`material-backup`。
- 保留报考单位不等于报考点、2026 代码只是基线、提交不等于审核通过等关键提示。

### 官方动态

- 原 `updates` 与 `sources` 完整迁移。
- 保留四类自动来源、缓存保护、新鲜度、关机后补查、重要决定回到官方原文等说明。
- 外链继续使用 HTTPS、`target="_blank"` 与 `rel="noopener noreferrer"`。

## 共享页面框架

每个页面使用同一套：

1. 跳过链接。
2. 品牌区和全局导航。
3. 页面标题区与可选页内目录。
4. 主内容。
5. 统一免责声明页脚。

全局导航标签固定为“首页 / 专业与备考 / 全年时间轴 / 报名材料 / 官方动态”。当前页面在静态 HTML 中直接设置 `aria-current="page"`，不能依赖 JavaScript 才获得正确语义。

移动端使用按钮控制的单列导航面板。按钮维护 `aria-expanded`，Escape 关闭后焦点回到按钮；桌面宽度下导航始终可见。主要导航项的点击区域至少 44px。

## 跨页进度模型

共享注册表是 21 个稳定 ID 的唯一允许集合。读取时只接受注册表中值为布尔值的字段；未知字段被丢弃。

保存算法：

1. 从存储重新读取最新全局对象。
2. 只用当前页面出现的复选框覆盖对应字段。
3. 保留其他页面注册 ID 的已有值。
4. 写回同一个 `hainanu-2027-kaoyan-progress-v1` 键。

全局完成数从注册表和已保存对象计算，不从当前 DOM 的复选框数量计算。首页即使没有任何任务复选框，也必须显示 `x / 21 项`。存储不可用时继续使用当前会话状态并显示已有警告，不得阻止页面初始化。

首页的重置按钮明确重置全部 21 项；确认文案必须说明范围。子页面不提供含糊的全局重置。

## 当前阶段模型

14 个里程碑的 `id/start/end/label/action` 放在共享 JavaScript 数据中。时间轴 DOM 仅用于视觉高亮、筛选和详细正文；首页状态面板直接从共享数据计算。这样拆页后仍能在 2026-08-25 显示“锁定专业基线”，并能随日期自动进入下一阶段。

## 官方动态摘要

实时控制台仍只在同时存在 `#live-updates-console` 与 `#refresh-official-updates` 时初始化。首页提供紧凑控制台，并在公告列表上声明显示上限 3；完整动态页不设上限。其他三个页面不放置这两个锚点，因此不会产生后台轮询。

渲染上限只影响显示，不影响 API 数据、未读识别、缓存和来源新鲜度计算。

## 服务端与安全

- `src/http-app.cjs` 为四个新 HTML 文件及四个无扩展别名增加显式映射。
- 所有静态页面继续支持 GET 和 HEAD；其他方法返回 405 和 `Allow: GET, HEAD`。
- 所有页面继续返回 `Cache-Control: no-store`、正确 content type 和现有 CSP/Referrer-Policy/nosniff。
- `%2e` 编码路径继续在解码前返回 403；未知文件、`server.cjs`、`data` 和项目内部文件继续返回 404。
- API 路由、刷新同源校验、1KB 请求体上限与冷却机制不变。

## 可访问性、响应式与打印

- 每页一个 `h1`；内容标题从 `h2` 开始。
- 当前页使用 `aria-current="page"`，当前时间节点使用 `aria-current="step"`，页内目录使用 `aria-current="location"`。
- 320px、360px、390px 无横向滚动；长标题、日期和 URL 可换行。
- 保留 `prefers-reduced-motion`、明显焦点样式、44px 触控目标和 `role="status"` 的礼貌播报。
- 打印时隐藏全局导航和交互按钮，保留“已完成/未完成”文字；专业、时间轴、报名材料和动态页可分别打印。

## 验收标准

- 五个页面及四个无扩展别名可 GET/HEAD，未知路径仍拒绝。
- 所有页面的共享 CSS/JS 均能载入，直接刷新不 404。
- 首页没有原单页的大段重复正文，首屏可直接看到当前阶段和去向。
- 在专业页、时间轴页、报名页各勾选一项后，首页显示 `3 / 21 项`，刷新和跨页后不丢失。
- 首页重置后 21 项全部清空；取消确认不改变状态。
- 首页阶段文案在没有时间轴节点 DOM 时仍动态准确。
- 首页只显示最多 3 条动态，动态页显示完整列表。
- 320/390/1440px 下导航可用、无横向溢出，当前页标识正确。
- Node 语法检查、完整自动测试、浏览器控制台检查和 HTTP 健康检查全部通过。
