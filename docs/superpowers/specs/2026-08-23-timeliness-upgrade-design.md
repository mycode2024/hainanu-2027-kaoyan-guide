# 海南大学 2027 考研导航：信息及时性升级设计

## 背景与审计结论

现有版本已经能抓取海南大学研究生院“硕士生招生”和计算机学院“研究生招生”两条官方列表，并具备缓存回退。但及时性链路仍有六个缺口：

1. 本地服务不运行时，浏览器会直接连接失败；隔夜或重启后不能假定服务仍在。
2. 后台每 6 小时刷新，关键公告最坏可能延迟 6 小时。
3. 页面每 15 分钟才读取一次后台快照，后台已更新后仍有额外延迟。
4. `GET /api/updates` 只返回缓存，到期时不会顺带发起补查。
5. 只监控两条校内列表，会漏掉海南大学研究生院首页的报考点公告，以及教育部/研招网发布的全国政策。
6. 缓存没有记录通知首次发现时间，也没有数据年龄语义，用户看不出“刚发现”还是“旧缓存”。

## 方案选择

### 方案 A：高频暴力轮询

每 5—10 分钟抓取全部来源。实现最简单，但会给官方站点造成不必要负担，也不能解决服务没有运行的问题，因此不采用。

### 方案 B：部署云端定时任务

可在电脑关机时继续运行，是真正的 24 小时方案；但需要托管账户、持久化服务和部署权限，也不再是当前用户要求的简单本地 Node.js 后端。本轮不扩张到云部署。

### 方案 C：本地及时性增强（采用）

后台每小时检查、单来源失败快速重试一次、API 在发现计划时间已过时后台补查、前端每分钟读取快照；增加两条官方来源、变更检测和可靠启动器。在控制请求量的同时，将服务运行时的最坏发现延迟降到约 1 小时，页面展示延迟降到约 1 分钟。电脑关机期间不承诺抓取，但下次启动立即补查。

## 官方来源

固定监控以下四条 HTTPS 白名单来源，不接受浏览器传入任意 URL：

1. 海南大学研究生院“硕士生招生” `https://gs.hainanu.edu.cn/yjszs/ssszs.htm`
2. 海南大学研究生院首页 `https://gs.hainanu.edu.cn/`，补充报考点报名、网上确认和预报名提醒
3. 海南大学计算机科学与技术学院“研究生招生” `https://cs.hainanu.edu.cn/zsgz/yjszs.htm`
4. 研招网“教育部政策” `https://yz.chsi.com.cn/kyzx/jybzc/`，补充全国招生工作管理规定、报名和复试政策

海南省考试局页面在本次审计中多次超时，不作为自动抓取源；报考点不在海南大学的考生仍需按页面提示关注自己所选报考点。

## 抓取与安全

- 每个来源声明 `allowedHosts` 和 `context`；链接和每一跳重定向都必须留在该来源白名单。
- 海南大学首页的 `[MM-DD]` 日期按检查时间推断年份：月份显著大于当前月份时视为上一年，避免上一招考周期跨年公告被误标。
- 研招网政策源只保留全国硕士研究生招生考试、研考和招生工作管理规定等直接相关标题。
- 每个来源失败后等待 750 ms 重试一次；两次均失败才进入缓存回退。
- 仍保留 12 秒超时、2 MB 流式响应上限、HTML 类型校验和零结果保护。

## 刷新与新鲜度

- `DEFAULT_REFRESH_INTERVAL_MS` 调整为 1 小时。
- 服务启动后立即刷新；自动定时器每小时刷新。
- `refreshIfDue()` 根据 `nextRefreshAt` 判断是否到期。`GET /api/updates` 在到期时异步触发刷新，先返回当前缓存，不阻塞页面。
- 前端每 60 秒读取一次 `/api/updates`，后台刷新完成后最迟约 1 分钟展示。
- `getSnapshot()` 动态附加 `freshness`：`fresh`、`aging`、`overdue` 或 `never`，并给出 `ageMs` 与 `isOverdue`。
- 每个来源保留 `lastSuccessAt`，单一来源失败时用户仍能看到该来源最后一次成功时间。

## 变更检测

- 每条通知增加 `discoveredAt`。已存在通知保留旧值，新 ID 使用本次 `fetchedAt`。
- 快照增加 `change`：`newCount`、`newIds` 和 `changedAt`。
- 首次从旧缓存升级时，不把所有历史通知伪装成刚发现；缺少 `discoveredAt` 的旧项使用缓存 `lastSuccessAt` 或通知日期补齐。
- 前端用本地 `lastSeenAt` 标出上次查看后发现的通知；第一次打开只建立基线，不把全部历史内容标红。

## 启动体验

- `scripts/launch.ps1` 先请求本地 API；服务已运行则复用，未运行则后台启动 Node，并用条件轮询等待最多 15 秒。
- 服务真正返回成功后再打开浏览器，去掉固定等待 2 秒造成的竞态。
- `start-guide.cmd` 作为兼容入口调用 PowerShell 启动器。
- 桌面增加 `海南大学2027考研导航.cmd`，用户无需进入项目目录。
- 运行日志按启动时间写入 `data/server-时间.log` 和 `data/server-时间.error.log`，保留每次启动记录便于排障。

## 数据契约 v2

保持现有字段并新增：

- `schemaVersion: 2`
- `freshness: { state, ageMs, isOverdue }`
- `change: { newCount, newIds, changedAt }`
- `sources[].lastSuccessAt`
- `updates[].discoveredAt`

旧缓存由 `sanitizeCachedSnapshot` 平滑升级；不合法来源、URL、日期和时间字段继续丢弃。

## 验收标准

- 四条真实官方来源均能解析到相关记录，重复链接只展示一次。
- 海南大学首页短日期和研招网政策标题的测试通过。
- 瞬时失败会重试一次；持续失败保留缓存。
- 到期读取会触发一次非阻塞刷新，并发读取不会产生重复上游请求。
- 新通知保留首次发现时间，旧通知不会在每次刷新时重新变“新”。
- 页面能显示数据年龄、新通知标签、四来源健康状态和 1 小时刷新节奏。
- 双击桌面启动器后，只有在首页与 API 可访问时才打开浏览器。
- 完整自动化测试、真实官网同步和本地启动验收全部通过。
