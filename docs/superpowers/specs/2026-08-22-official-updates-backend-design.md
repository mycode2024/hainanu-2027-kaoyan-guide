# 海南大学 2027 考研导航：官方动态后端设计

## 目标

在不破坏现有静态导航的前提下，增加一个可本地运行的 Node.js 后端，自动读取海南大学官方招生通知，并把最新状态展示在网页中。

## 已确认的信息源

- 海南大学研究生院“硕士生招生”：`https://gs.hainanu.edu.cn/yjszs/ssszs.htm`
- 海南大学计算机科学与技术学院“研究生招生”：`https://cs.hainanu.edu.cn/zsgz/yjszs.htm`

只抓取上述官方域名。通知详情仍由用户点击官方原文查看，本站不复制正文，也不把推测日期改写为官方日期。

## 选定方案

采用 Node.js 内置模块实现，不引入 npm 运行依赖：

1. `server.cjs` 同时提供静态文件和 JSON API，仅监听 `127.0.0.1`。
2. 服务启动后异步抓取两条官方信息流，此后每 6 小时自动刷新。
3. 成功结果原子写入 `data/updates-cache.json`；刷新失败时继续使用最近一次成功缓存。
4. `GET /api/updates` 立即返回当前快照；`POST /api/refresh` 触发手动同步。
5. 前端实时面板展示来源健康状态、上次成功时间、下次自动同步时间和最新通知。
6. 直接双击打开 `index.html` 时，原有静态导航继续可用；实时面板提示需要启动本地服务。

## 数据契约

API 返回对象包含：

- `status`: `fresh`、`stale` 或 `seed`
- `fetchedAt`: 最近一次刷新尝试时间
- `lastSuccessAt`: 最近一次成功更新时间
- `nextRefreshAt`: 下次计划刷新时间
- `refreshIntervalMs`: 刷新周期
- `sources`: 每个官方来源的成功/失败状态
- `updates`: 去重、按日期倒序排列的通知
- `error`: 所有来源均失败时的简要错误

每条通知包含 `title`、`date`、`url`、`source`、`sourceId`、`category`、`isTarget2027` 和 `isImportant`。

## 抓取与排序规则

- 从列表项中识别标题、链接和 `YYYY-MM-DD` 日期，兼容研究生院的 `<span>` 日期和计算机学院的 `<i>` 日期。
- 将相对链接解析为对应官方绝对地址，清理 HTML 实体和多余空白。
- 只保留与硕士招生、报名、目录、初试、复试、调剂、录取等相关的内容。
- 2027、专业目录、招生简章、报名、初试科目、复试等目标通知优先显示；同优先级按日期倒序。
- 同一链接或标题只显示一次。

## 安全与故障处理

- 仅允许预设的 HTTPS 官方来源，不接受来自浏览器的任意抓取 URL。
- 每次网络请求设置 12 秒超时和固定 User-Agent；手动处理重定向，每一跳都必须仍在海南大学官方域名。
- 响应按流计数，超过 2 MB 立即停止读取；非 HTML 响应不进入解析器。
- API 限制方法并限制请求体大小；静态文件服务阻止目录穿越。
- 手动刷新 API 要求页面专用请求头，并拒绝跨站来源，防止其他网页滥用本机服务。
- 页面渲染只使用 DOM `textContent` 和已校验的 `https://*.hainanu.edu.cn` 链接。
- 单一来源失败时保留另一来源的新数据并标注失败来源；全部失败时使用旧缓存。
- 缓存不存在且网络失败时返回 `seed` 空状态，而不是错误退出。

## 验收标准

- 两种官方列表 HTML 均可正确解析。
- 自动刷新成功时会持久化；失败时不会覆盖成功缓存。
- 并发刷新只发起一组上游请求。
- 静态页面和两个 API 路由均可访问，错误方法得到明确状态码。
- 前端能区分实时、缓存和未启动后端三种状态。
