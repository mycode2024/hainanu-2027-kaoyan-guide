01 / 报名操作台

报名不是填表，
是一次信息校验

唯一官方入口是中国研究生招生信息网。建议用电脑操作，每完成一屏就截图，最终保存报名信息表和报名号。

你要报考的学校报考单位

海南大学（2026 基线代码 10589）

≠
你参加初试的组织地点报考点

由就读学校 / 户籍 / 工作所在地规则决定

  1. 01

    登录研招网，先核对学信网账号

    确认手机号、证件号、姓名和学籍学历信息可正常使用。不要临近截止才处理账号或学籍校验问题。

  2. 02

    先读四类公告，再打开填报

    教育部报考须知、省级考试机构公告、拟选报考点公告、海南大学 2027 招生章程与目录。四者都可能有约束。

  3. 03

    填写考生信息

    学籍学历、基本信息、户籍档案、家庭成员、学习工作经历、奖惩、联系方式。档案所在地要写到能实际接收调档函的单位。

  4. 04

    填写报考信息

    招生单位海南大学2026 基线 10589
    院系所计算机科学与技术学院2026 基线 812
    专业081200 / 085404 / 085405只选一个
    考试方式全国统一考试普通统考生
    学习方式全日制按目标专业目录
    就业方式非定向就业普通全日制常见选择，须按本人情况

    以上代码和选项是 2026 基线示例。填报时必须以系统中 2027 可选项和本人身份为准，不要机械照抄。

  5. 05

    按资格选择报考点

    应届本科生原则上选择就读学校所在地指定报考点；其他考生通常选择工作或户口所在地指定报考点。海南大学海甸、儋州报考点是否接收你，以当年公告为准。

  6. 06

    生成报名号后做“十字段复核”

    证件、学历、招生单位、院系、专业、方向、学习方式、考试科目、专项计划、报考点逐项复核。报名号同时保存到手机备忘录。

  7. 07

    完成缴费，确认唯一有效报名

    以页面显示的缴费状态为准。需要重报时先看清原信息与费用处理规则，最终只保留一条确定使用的有效信息。

  8. 08

    网上确认后盯到“审核通过”

    上传材料只是开始。反复查看结果，退回就及时补交；审核通过后保存截图。报名与确认缺一不可。

02 / 材料清单

提前建一个文件夹，
别在截止前找证件

下列是通用准备清单。照片尺寸、证明时效和具体格式由你选择的报考点决定，最终应逐项对照报考点当年网上确认公告。

同等学力、跨专业、学历校验未通过，需要额外注意什么？

海南大学招生简章与目录可能对部分专业设置课程、论文或加试要求。学历学籍校验未通过的考生需要在学校规定时限前提交核验材料。计算机学院 2026 基线中，081200 与 085404 同等学力加试为离散数学和 C 语言，085405 为离散数学和 Java 程序设计；2027 必须重新核对。
